# Matricula

M1: examen de clasificación, matrícula autogestionada con bloqueos (prerrequisito, pago, vacantes), ficha de matrícula, traslados y retiros, y reportes del estudiante por periodo (avance de notas, asistencia, boleta, horario y récord en PDF).

Public API for other modules: `Contracts/`, `Data/` (DTOs), `Events/` and `Enums/`. Everything else is internal. See `docs/arquitectura.md`.
